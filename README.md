# Guida al Piano Sanitario — Scuola e Ministero

App web statica, a pagina singola, che riassume in modo navigabile la **Guida al Piano sanitario per il Personale della Scuola e del Ministero** (Edizione 2026, UniSalute).

🔗 **Demo:** dopo aver pubblicato con GitHub Pages (vedi sotto), sarà disponibile su:
`https://<tuo-utente>.github.io/<nome-repo>/`

## Contenuto

Il sito è organizzato in 9 sezioni consultabili dal menu laterale:

1. Panoramica
2. Come funziona (strutture convenzionate vs non convenzionate)
3. Servizi online e app
4. Chi è assicurato
5. Prestazioni coperte (voce per voce, con massimali e scoperti)
6. Cosa non è coperto
7. Informazioni pratiche
8. Reclami e tutele
9. Contatti

## Tecnologia

Un solo file HTML autonomo (`index.html`), senza dipendenze da installare: HTML, CSS e JavaScript vanilla, con i font caricati da Google Fonts via CDN. Funziona aprendo semplicemente il file in un browser, oppure pubblicato online.

## Pubblicare su GitHub Pages

1. Crea un nuovo repository su GitHub (pubblico) e carica il contenuto di questa cartella.
2. Vai su **Settings → Pages**.
3. In **Source**, seleziona il branch `main` e la cartella `/ (root)`.
4. Salva: dopo qualche minuto il sito sarà online all'indirizzo indicato da GitHub.
